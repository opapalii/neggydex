Se comprobó a 375, 768 y 1440 px la navegación, búsqueda, favorito, apertura y cierre de ficha, cálculo manual, creación y guardado de equipo, elección de dificultad, apertura de Pokéwordle y ajustes. Cuatro juegos de adivinanza se resolvieron con datos reales. El intento automatizado de terminar un combate después de atacar agotó el tiempo esperando el control de rendición; no se considera verificado el final de ese combate. La suite del repositorio aporta pruebas adicionales, pero estas comprobaciones no cubren todos los botones y estados posibles.
